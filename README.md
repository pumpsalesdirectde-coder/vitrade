# MIVTrade

Личный стенд бумажной торговли DCA-ботами по живым ценам Bybit. Реальные ордера не отправляются.

## Вилка

Раздел `#/fork` содержит отдельные настройки для каждого основного бота. По умолчанию вилка выключена; включается отдельно для каждого бота. Условия запуска: рост на 20% от минимума наблюдаемого минутного окна **или** на 50% от первого входа в текущий шорт. Все условия и параметры выхода изменяются в форме.

Лонг рассчитывается по фактическому оставшемуся объёму шорта со всеми исполненными докупками и частичными закрытиями. Цель — заданный общий результат на следующем шаге роста от цены открытия вилки. Расчёт включает комиссии биржи, проскальзывание, известный фандинг и комиссию кошелька 20% с прибыли каждой стороны. Значение «Общий итог» поэтому отличается от PnL одного торгового счёта.

Начальные настройки: наследовать шаг и плечо шорта, допустимый убыток 1% бюджета шорта, лимит маржи лонга 2 бюджета шорта, дополнительный стоп 3% бюджета от результата сразу после открытия пары, время 30 минут. Для безубытка задайте допустимый убыток 0%. Увеличение лимита маржи не задаёт фиксированный объём лонга.

Открытая пара запрещает докупки и частичные закрытия. Обе стороны закрываются вместе по общему результату, стопу, времени, ликвидации или ручной команде; после этого оба бота останавливаются. При выключении защиты уже открытая пара продолжает сопровождаться с зафиксированными настройками. Недостаточный бюджет, неисполняемые котировки или недостижимая до ликвидации цель не приводят к открытию неполной страховки. Большой лонг при развороте способен увеличить убыток; целевая цена — прогноз, фактический выход проверяется по bid/ask.

Проверки: `node --test "server/**/*.test.js" "web/src/*test.js"`. Исходная загруженная версия сохранена в архиве `../VIMTrade.zip`; резервная копия локальной базы перед обновлением — `data/pre-fork-20261114.sqlite`.

## Запуск

```
npm install
npm run build
npm start            # http://127.0.0.1:4180
```

Импорт счетов из VITrade 0.1.0 (старая база открывается только на чтение):

```
npm run import -- "D:/Project/VITrade-run/.../VITrade/data/vitrade.sqlite"
```

Разработка интерфейса: `npm start` в одном окне, `npm run dev` в другом (http://localhost:5173).
Тесты движка: `npm test`.

## Публичный тест на Render

`render.yaml` описывает сервис: план Starter (не засыпает), регион Frankfurt, диск 1 ГБ в `/var/data` под базу,
проверка здоровья `/api/health`. На Render сервер слушает `0.0.0.0:$PORT`, принимает POST только со своего
адреса `RENDER_EXTERNAL_URL`, ставит cookie с флагом Secure и берёт IP клиента из `x-forwarded-for`.
`VITRADE_MAX_USERS` ограничивает число регистраций (0 — без ограничения).

## Устройство

- `server/engine` — учёт позиции, сетка докупок, тейк и стоп, подушка маржи, фандинг, команды бота; сигналы RSI и стадий памп-цикла.
- `server/market` — публичные данные биржи (сейчас Bybit).
- `server/net.js` — сетевая политика: наружу только GET к перечисленным адресам рыночных данных.
- `server/runner.js` — раз в секунду продвигает счета, раз в 5 секунд обновляет рынок.
- `server/http.js` — API и раздача интерфейса; локально слушает только 127.0.0.1, POST принимаются только со своего адреса.
- `web/` — интерфейс (React + Vite).
